This is a simple to-do list with a random task selector and pomodoro timer built in.
You start by entering your To-dos for the day. Then you can use this in a few ways:
1. You can just use this as a simple to-do list. Write things down and click x to cross it off.
2. You select a todo and have it start a pomodoro timer for that todo.
3. Lastly, you can use the random selector. This randomly selects a todo for you and offers to start the pomodoro timer for you.
4. At the end of the day you carry over your unfinished todos to the new list or start totally fresh.  

New update adds "Creativity mode". This adds a new setting where after 4 (or any amount, based on settings) completed to-dos, it prompts a 15 minute creativity break to do something other than work.
New settings allow you to define timer lengths and number of tasks to trigger "creativity mode" 
Allow for manual to-do selection toggling, in case you don't want to let yourself manually select a to-do and live by the die.
